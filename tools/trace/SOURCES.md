# Sources of the traced hands

Full credits live in one file per source, `tools/trace/sources/<source-id>.md`; download URLs and the rights read
on each holder's page live in `tools/trace/manifest/<source-id>.json`. We copy letter **structure** as new
centerline drawings and never copy or display a source's text. To add a source, add those two files and one line
below, kept in alphabetical order by id.
