# Security

If This Finds You is a static site: there are no accounts, no passwords and no server-side data. Letters you write stay
in your browser unless you share a link. Still, if you find a way to make the site or its code do something it
shouldn't, please tell us privately first.

## Reporting a problem

Use GitHub's private reporting: **[Report a vulnerability](https://github.com/rafaelcespedes/if-this-finds-you/security/advisories/new)**
(the Security tab, then "Report a vulnerability"). Please don't open a public issue for it.

Say what you found, how to reproduce it, and what someone could do with it. You'll hear back as soon as possible, and
you'll be credited when it's fixed, if you'd like to be.
