# Design principles

Rules every workstream follows. Most come straight from Rafael.

1. **No hard rule that isn't a hard rule in real life.** Anything a real writer doesn't keep perfectly
   consistent gets seeded, correlated variance: line height, baseline, margins, letter size, spacing,
   staying on the ruled line, slant, ink density. Keep it subtle and legible by default, scaled by
   Neatness, but present everywhere. "When I write in real life, I don't always stick to the lines.
   My line heights are not always consistent... that's part of the beauty of writing in a notebook."
2. **Real hands are allowed to be ugly.** Overlap, cramping, sprawl and mess are part of human writing.
   Only bugs get fixed, never taste. (Rafael, 2026-11-02)
3. **Every new hand should feel like a different person.** Variety comes from letter *construction*
   (allographs from real traditions), not only from proportions. New hand also changes print/script.
4. **Inclusive by default.** Draw on handwriting traditions from many countries and languages, from
   both famous and ordinary writers. Credit every source. Never present a culture's hand as an exotic
   "style".
5. **Variation is layered and correlated**: writer → page → line → word → letter → stroke. It is never
   independent dice per letter.
6. **Ink is physical.** Ink density follows pen speed and pressure, crossings darken, colour is never
   flat, and once written, ink stays put (see the Ink mode research).
7. **Honest about limits.** The live page varies endlessly. An exported font file can only cycle a few
   versions per letter, and we say so plainly.
8. **Open provenance.** Every skeleton carries its source, and the reference library lists everything
   we used and how it shaped a decision.
9. **Minimal, warm, polished UI.** The letter is the hero; controls stay few and are written in plain words.
10. **Archival look, 2026 interaction.** Typography and surfaces may feel like a museum or library; controls, panels,
    sheets and motion must feel modern: snappy, smooth, interruptible, thumb-friendly, one shared overlay system.
    (Rafael, 2026-11-03)
11. **No hard lines.** Dividers and edges are soft (low-contrast ink, never near-black), so nothing competes with the
    handwriting. (Rafael, 2026-11-03)
