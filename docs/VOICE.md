# Voice

How If This Finds You speaks, in its own words (labels, hints, messages, page titles). The letters' texts,
writers' names, source credits and licence wording are not ours to change. Written 3 November 2026 from a pass
over the whole site; examples are the site's own lines.

**In one line:** a quiet reading room. Plain, warm, exact, like a museum label written by someone who loves
the objects. There's nothing to sell.

## Ten rules

1. **Say what is there.** Describe the object or the action, then stop.
   *Real letters by ordinary people, each written out by hand.* Not "Discover a world of…".

2. **The words are real; the hand is not. Say both, every time it matters.** Never imply the handwriting is
   the original writer's.
   *The words are the original writer's. The handwriting is Ilse Pryor's, a writer who never existed.*

3. **One name per thing.** Pick the word and keep it across the tool, the library and Fonts.
   See the glossary below. Different words for one action make people think there are two.

4. **Buttons are verbs; headings are nouns.** Verbs say what happens: *Write a reply*, *Find another*,
   *Copy link*, *Download image*. Headings name a place or object: *All letters*, *Writing materials*,
   *Full record*.

5. **Short beats long, and plain beats clever.** A label is two or three words. A hint is one sentence.
   *Find a neater hand*, not "Roll a neat one".

6. **Sentence case, and no full stop on a heading or a button.** Body sentences end with one.
   *This letter couldn't open* (heading) → *Check your connection, then try again.* (body)

7. **Errors say what happened, then what to do.** No blame, no apology, no "Oops".
   *The ink is dry. Cross it out, or start a fresh sheet.*
   *Part of the letter didn't arrive. Some apps shorten long links, so ask the sender to share it again.*

8. **Be honest about limits, in the same quiet tone.**
   *A font keeps four or five versions of each letter, so it repeats where the page doesn't.*
   *These hands write the Latin alphabet.*

9. **Talk to the reader as "you"; the site rarely says "we".** "We" appears only where a person is speaking for
   the project (the About page, *How we know*).

10. **No exclamation marks, no AI tells.** No "not X, it's Y", no "no X, no Y, no Z", no colon reveals, no stock
    openers, no em dashes in labels or titles. Contractions are fine (*couldn't*, *isn't*); use them throughout.

## Glossary: one word for each thing

| Thing | Say | Not |
|---|---|---|
| What the user writes | letter (*your letter*, *a reply*) | note, draft, document |
| A letter in the collection | letter, *a found letter* | item, entry, record (except *Full record*, the catalogue card) |
| The collection | *All letters*, *the collection* | the library, the archive, the database |
| The person who copies a letter out | writer, *a fictional writer*, *a writer who never existed* | AI, model, generator |
| Their handwriting | hand (*in Ilse Pryor's hand*) | font (except on Fonts), style |
| New letter and new hand | *Find another* (tool), *Bring another* (Reading Room) | shuffle, roll, randomise |
| Same letter, new hand | *Change writer* (tool), *Another hand* (letter page) | reroll, regenerate |
| Paper, pen, ink as a group | *Paper, pen and ink*; *Writing materials* (Reading Room) | settings, options, & |
| Sharing | *Share* (the button), *Copy link* (the action), *Link copied* | share a link, send |
| Saving a picture | *Download image*, *Image downloaded* | save as an image, export, image saved |
| The letter's words without the hand | *Read as text*, *Hide the text* | transcript, plain text (except *Edit as plain text* in the writing menu) |
| The downloadable hand | font, *Download the font*, *Font downloaded* | export, file |
| The font's limit | *four or five versions of each letter* (four for joined hands, five for print; see docs/FONTS.md) | a few versions, alternates, cycles |
| Title separator | *Fonts · If This Finds You* | – , \|, : |

## Where it applies

The tool (desk, sheets, menus, toasts), All letters (canvas, list, letter pages), Fonts, the 404 page, page
titles, meta and share-card text, aria-labels and tooltips (they say what the visible words say). The About
page follows the same rules in a longer form.
